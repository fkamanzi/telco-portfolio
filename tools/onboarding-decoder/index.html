Drop in SIM-swap messages

A CSV with one message per row: an SMS PDU in hex from the SMSC, OTA platform or a phone log, or an entitlement server answer in XML or JSON. It is read in your browser and never leaves this page.

Expected columns (any order, matched loosely): payload (SMS PDU in hex with or without the SMSC prefix, SMPP user data, or a TS.43 answer), optional time, direction (MO or MT), subscriber (masked IMSI, MSISDN or a label), source. Decodes 3GPP TS 23.040 SMS (PID, DCS, user data header, concatenation, ports), TS 31.115 SIM over-the-air command and proof-of-receipt packets (SPI, KIc, KID, TAR, status), OMA Client Provisioning (WBXML), OMA DM notifications, GSMA RCC.14 configuration SMS and GSMA TS.43 entitlement answers. Handset-change reports use vendor formats: IMEI and IMSI are found by pattern and checked. Method: a swap starts at a handset-change report and is stalled if no settings, SIM update or notice follows within the window.
