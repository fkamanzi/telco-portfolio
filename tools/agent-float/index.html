Drop in agent transactions

A CSV of agent transactions with the e-float balance after each one, from your mobile-money or agent-banking platform. It is read in your browser and never leaves this page.

Expected columns (any order, matched loosely): agent (agent or till id), time, type (cash in, cash out, rebalance, other), amount, float_after (e-float balance after the transaction), optional status (success, failed), reason (insufficient float, other) and area. Method: per agent in time order, a low-float episode runs from the first balance below the minimum to the first balance back at or above it (the time to rebalance); a failure counts only where the file marks it as failed for insufficient float. Cash-outs and rebalances never count as float failures.
